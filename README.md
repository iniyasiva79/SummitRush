# Summit Rush

**Turn everyday tasks into a race to the summit.**

SummitRush is a mountain-themed productivity web application that makes completing real-life tasks more engaging through game-inspired challenges and friendly competition. Instead of treating a to-do list as another chore, SummitRush encourages users to make progress toward a virtual summit as they complete tasks.

**Live Demo:** https://summitrush.vercel.app  
**GitHub Repository:** https://github.com/iniyasiva79/SummitRush

## About the Project

SummitRush was developed for CrownHacks 2026 at UNC Charlotte in the Creative Track.

Our goal was to make productivity more interactive and motivating by combining everyday task management with mountain-climbing challenges, competition, and rewards.

The application is designed to encourage users to complete tasks, track their progress, and stay motivated through a game-inspired experience.

## Key Features

- **Mountain-Themed Interface:** An original animated mountain landscape with an interactive design.
- **Play and Private Rooms:** Options designed for individual challenges and competition with friends.
- **User Accounts:** Sign-up and login functionality with personalized user profiles.
- **Coins and Rewards:** A virtual coin system designed to reward progress and encourage participation.
- **Accessibility Settings:** Customizable sound, reduced motion, high contrast, and text size.
- **Competitive Gameplay:** Planned features include mountain races, Chaos Cards, bonuses, progress tracking, and wins/losses.

**Project Status:** SummitRush is an evolving project. Some competitive gameplay, reward, and tracking features are still under development.

## How to Run the Project

1. Clone the GitHub repository:

```bash
git clone https://github.com/iniyasiva79/SummitRush.git
```

2. Navigate to the project directory:

```bash
cd SummitRush
```

3. Install the dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open http://localhost:3000 in your browser.

Check the `.env.example` file for any required environment variables. Never upload private API keys or credentials to GitHub.
